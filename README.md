# House Price Prediction

An end-to-end machine learning project that estimates the sale price of a house.

## Status
Work in progress. Phases 1 to 3 done (problem definition, dataset, project setup).

## Project structure
See the folder layout in this repository. Code lives in `src/`, notebooks in `notebooks/`, documents in `docs/`.

## Setup
1. Create a virtual environment: `python -m venv .venv`
2. Activate it: `.venv\Scripts\Activate.ps1` (Windows)
3. Install packages: `pip install -r requirements.txt`
4. Download `AmesHousing.csv` (see `docs/dataset_notes.md` for the source) and put it in `data/raw/`.
